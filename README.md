# CARD TWO SIGHT · 카투사

Java와 libGDX로 만든 2인 숫자 심리전 보드게임의 실행 가능한 1차 버전입니다. 정지 시안을 게임 배경·캐릭터·카드·리볼버 자산으로 나누고, 버튼과 숫자·점수·화면 전환은 코드로 연결했습니다.

## 바로 실행

Windows에서 Java 17 이상이 필요합니다. 개발 시 JDK 21.0.12로 검증했습니다.

- 실행본 압축을 모두 풀고 **게임실행.bat**을 두 번 클릭합니다.
- 이 소스 폴더에서는 **게임실행.bat**을 실행합니다. 실행본이 없으면 처음에 빌드하며 인터넷이 필요합니다.
- VS Code에서는 이 폴더를 열고 권장 Java 확장을 설치합니다.
- F11: 전체 화면 전환 / ESC: 이전 화면 또는 테이블 나가기.

첫 확인은 **테이블에 앉기 → 캐릭터 선택 → 선택 완료 → 닉네임 입력 → 연습 테이블 입장 → 준비하기 → 게임 시작** 순서입니다.

## 두 사람이 함께 접속

1. 두 PC를 같은 공유기·학교 내부망에 연결합니다.
2. 방장: 서버 주소 `127.0.0.1`, 포트 `54555`, 비밀번호를 입력하고 **내 PC에서 서버도 실행: 켜짐 → 방 만들기**.
3. 참가자: 방장 PC의 IPv4 주소, 같은 포트와 방 비밀번호를 입력하고 **방 입장**.
4. 두 사람 모두 준비하기를 누르고, 방장이 게임 시작을 누릅니다.

같은 PC에서도 게임을 두 번 실행해 시험할 수 있습니다. 두 번째 창은 주소를 `127.0.0.1`로 둡니다. 방장 PC에서 게임을 종료하면 내장 서버도 종료됩니다. 연결되지 않으면 주소·포트·네트워크 및 Java의 방화벽 허용 상태를 확인하세요.

별도 서버는 **서버실행.bat**으로 실행합니다. 이 경우 방장은 내장 서버 옵션을 끄고 해당 서버 주소로 방을 만듭니다. 인터넷 전역 접속용 서버 배포·암호화·계정 인증은 포함하지 않았습니다. 방 비밀번호는 방 식별용 단어입니다.

## 구현된 내용

- 메인 / 설정·게임 방법 / 6인 캐릭터 선택 / 접속 / 2인 대기방
- 1~9 타일 선택, 9라운드, 1이 9를 이기는 예외, 무승부
- 역전·정찰·위장·예측 카드와 개인 정보 분리
- 9탄실 룰렛, 목숨 3개, 승패에 따른 위험도 변화
- 칩을 사용하는 4종 힌트, 탄실 선택, 격발 확인, 상대 준비 대기
- 룰렛 결과·최종 승패·다시 하기·연결 종료 처리
- 설정과 누적 승패를 한글 키의 `기록.json`으로 저장
- 연습 상대와 실제 Java Socket 통신 방식의 2인 대전
- 배경·캐릭터·카드 이미지, 기본 효과음, 회전·반동·피격 기울임

이미지 시안의 긴 총격 영상 전체를 재현한 버전은 아닙니다. 현재는 2D 정지 자산에 짧은 동작과 결과 연출을 연결했습니다. 연습 상대는 무작위로 행동하는 기본 상대입니다.

## 폴더 구조

```text
card-two-sight/
  assets/              게임에서 사용하는 그림·글꼴·효과음
    backgrounds/       공통 카지노 배경
    characters/        선택 가능한 인물 6명
    cards/             빈 숫자 카드와 특수카드 4종
    revolver/          리볼버와 빈 탄창 판
    audio/             기본 효과음
    fonts/             한글 글꼴과 사용권
  common/              공통 규칙·명령·개인별 상태
  server/              방 생성·입장·Socket 서버
  core/                화면·입력·통신 클라이언트·기록 저장
  lwjgl3/              데스크톱 실행 시작점
  design/              기존 전체 화면 시안 — 참고용
  docs/                규칙·연결 약속·역할·이미지 출처
  tools/               효과음·배포 생성 도구
```

**메인·게임·캐릭터 선택·리볼버는 화면별 Java 파일로 분리했습니다.** 그림은 `assets`에, 실제 작동은 `core/src/main/java/kr/ac/c2s/screens`에 있습니다. 전체 화면 시안을 버튼까지 한 장으로 띄우는 방식이 아닙니다.

## 개발 명령

PowerShell에서 프로젝트 폴더를 열고 실행합니다.

```powershell
.\gradlew.bat test
.\gradlew.bat :lwjgl3:run
.\gradlew.bat :lwjgl3:installDist :server:installDist
.\gradlew.bat :server:run --args="54555"
```

처음 실행 시 Gradle과 Maven 라이브러리를 다운로드합니다. Java 17 이상 JDK를 사용하세요. 라이브러리 버전은 프로젝트에 고정했습니다.

자동 화면 검증은 `검증실행.bat`입니다. 별도 테스트 데이터 폴더에서 연습 게임을 끝까지 진행하고 `.runtime/preview`에 실제 렌더링 PNG와 PASS/FAILED 결과를 남깁니다. 이 모드는 숨김 창으로 실행되며 일반 게임 실행에는 적용되지 않습니다.

## 저장 위치 및 상태

기본 저장 위치는 Windows 사용자 폴더의 `.card-two-sight/기록.json`입니다. 실제 돈 결제·현금 배팅 기능은 없습니다. 같은 경기의 최종 결과가 반복 수신돼도 기록은 한 번만 반영합니다.

검증 범위와 남은 작업은 [검증 결과](docs/VALIDATION.md)를 확인하세요. 자산 제작 이력은 [자산 안내](docs/ASSETS.md)에 있습니다.

룰렛 자세 애니메이션·효과음·섬광·목숨 표시 개선 사항은 [룰렛 연출 안내](docs/ROULETTE_ANIMATION.md)를 참고하세요.

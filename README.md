# CARD TWO SIGHT · 카투사

Java와 libGDX로 만든 2인 숫자 심리전 게임입니다. 숫자 대결·특수카드·칩 베팅·리볼버를 결합하며, 연습 모드와 TCP 소켓 기반 온라인 모드를 제공합니다. 배경·캐릭터는 이미지로, 버튼·숫자·입력·화면 전환은 Java 코드로 구성합니다.

## 실행

Java 17 이상 JDK가 필요합니다. 개발 환경은 Windows / JDK 21.0.12 / Gradle 8.14.3입니다.

- 프로젝트 폴더의 `게임실행.bat`을 실행합니다. 실행할 때 Gradle로 실행본을 빌드·갱신합니다.
- 최초 빌드에는 Gradle과 의존성을 내려받을 인터넷 연결이 필요합니다.
- 연습: 메인 → 캐릭터 선택 → 접속 화면에서 연습 모드 → 대기방 준비 → 게임 시작.
- F11: 전체 화면 전환. ESC: 화면에 따라 뒤로 가기·테이블 나가기.

## 온라인 접속

1. 방장: 주소 `127.0.0.1`, 포트 `54555`, 직접 정한 방 비밀번호를 입력합니다. 내 PC 서버 실행 옵션을 켜고 방을 만듭니다.
2. 같은 내부망의 참가자: 방장 PC의 IPv4 주소와 같은 포트·비밀번호로 입장합니다.
3. 두 사람 모두 준비하고 방장이 게임을 시작합니다.

`127.0.0.1`은 현재 컴퓨터 자신을 뜻하며 다른 PC가 방장에게 접속할 주소가 아닙니다. 같은 PC에서 게임을 두 번 실행할 때는 두 창 모두 이 주소를 사용할 수 있습니다. 방장 게임을 종료하면 내장 서버도 종료됩니다.

별도 서버는 `서버실행.bat 54555` 또는 아래 개발 명령으로 실행합니다. 이 경우 게임의 내 PC 서버 실행 옵션은 끄고 서버 주소로 방을 만듭니다. 서버 터미널은 켜둡니다.

```powershell
.\gradlew.bat :server:run --args="54555"
```

다른 네트워크에서 접속하려면 공인 IP·TCP 포트포워딩·방화벽 설정 또는 별도 네트워크 구성이 필요합니다. 실제 두 PC 및 외부망 접속은 아직 확인이 필요합니다. 암호화·계정 인증·중앙 매칭 서버는 구현하지 않았습니다. 방 비밀번호는 방 식별용이며 영문·숫자·한글 3~16자로 설정합니다.

## 현재 기능

- 인트로, 메인, 설정·게임 방법 팝업, 캐릭터 6명, 접속·대기방, 특수카드 2장 선택
- 숫자 타일 1~9를 한 번씩 사용, 1이 9를 이기는 예외, 최대 9라운드
- 역전·정찰·위장·예측: 위장은 상대에게 표시할 홀수·짝수를 직접 선택
- 각자 시작 30칩을 베팅·힌트 구매에 공용으로 사용
- 라운드마다 1~3칩 베팅, 적은 금액만큼 승부, 초과분·무승부 반환, 0칩이면 0칩 진행
- 베팅 차감·정산 숫자 효과와 별도 칩 계산 내역. 경기 기록에는 베팅 줄을 표시하지 않음
- 탄실 9개·초기 실탄 1발·목숨 3개, 패배 시 빈칸 직접 장전, 회전·격발·피격 연출
- 범위 탐색 4칩 / 탄실 검사 8칩, 라운드당 둘 중 하나만 구매
- 쉬움·보통·어려움의 규칙 기반 AI, 연습 상대 캐릭터 선택
- 최종 결과, 다시 하기, 연결 종료 처리, 설정·누적 승패 JSON 저장

최종 승패는 목숨과 숫자 대결 승수로 판정하며 보유 칩 수로 정하지 않습니다. 학습형 AI와 실제 돈 결제는 사용하지 않습니다. 온라인·AI 연습 경기 결과는 MySQL·JDBC로 저장·조회하며 로그인은 사용하지 않습니다.

## 폴더 구조

```text
card-two-sight/
  assets/                  게임 이미지·글꼴·효과음
    backgrounds/           카지노 배경
    characters/            선택 캐릭터 6명
      roulette/            격발·반응 자세 이미지
    cards/                 숫자 카드 바탕·수정 버전
      specials/            특수카드 4종과 수정 버전
    revolver/              리볼버·탄창 바탕 이미지
    audio/                 클릭·장전·회전·격발 효과음
    fonts/                 나눔명조·나눔고딕 파일과 라이선스
    intro/                 인트로 자산
    ui/                    메뉴 로고·버튼·장식 자산
  common/                  공통 규칙·명령·플레이어별 상태·규칙 테스트
  server/                  TCP 서버·방 생성/입장·통신 테스트
  core/                    게임 화면·입력·클라이언트·AI·기록 저장
  lwjgl3/                  데스크톱 실행 시작점·자산 패키징
  design/                  전체 화면 참고 시안
  docs/                    규칙·통신 규격·역할 제안·자산 안내
  tools/                   합성 효과음·배포 생성 도구
  gradle/                  Gradle Wrapper 설정
```

Java 소스는 각 모듈의 `src/main/java/kr/ac/c2s/` 아래에 있습니다. 예를 들어 화면은 `core/src/main/java/kr/ac/c2s/screens/`입니다. `.gradle/`, `build/`, `bin/`은 빌드·개발 도구가 만든 파일이며 게임 소스 구조와 구분합니다.

## 개발 명령

프로젝트 폴더에서 실행합니다.

```powershell
.\gradlew.bat test
.\gradlew.bat :lwjgl3:run
.\gradlew.bat :lwjgl3:installDist :server:installDist
.\gradlew.bat :server:run --args="54555"
```

`검증실행.bat`은 테스트·게임 빌드 후 숨김 창으로 연습 게임을 진행하고 `.runtime/preview/`에 화면과 PASS/FAILED 결과를 남기는 개발용 도구입니다. 현재 코드에서 실제 실행한 결과만 검증 근거로 삼습니다.

## 저장과 문서

온라인은 서버에서, AI 연습은 이 PC에서 종료 시 MySQL에 결과를 저장합니다. `DB기록조회.bat` 또는 MySQL 터미널에서 조회합니다. 이 PC의 로컬 DB는 게임·서버 실행 스크립트가 필요할 때 시작합니다. 설치·접속 설정은 [DB 안내](docs/DATABASE.md)를 참고하세요.

설정·누적 승패는 사용자 폴더의 `.card-two-sight/기록.json`에 저장합니다. 같은 경기의 결과는 중복 집계하지 않습니다. `c2s.dataDir` 설정으로 검증용 저장 폴더를 분리할 수 있습니다.

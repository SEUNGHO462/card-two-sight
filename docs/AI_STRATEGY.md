# 연습 상대의 숫자 선택 전략

## 적용 범위

어려움 난이도의 숫자 선택을 개선합니다. 쉬움의 낮은 숫자 3장 내 무작위 선택과 보통의 전체 무작위 선택은 유지합니다. 특수카드·힌트·탄실의 기존 행동 규칙도 유지합니다.

## 상대 정보의 사용 범위

`Snapshot.opponentObservations`에는 해당 플레이어가 완료된 라운드에서 알 수 있었던 정보만 기록합니다.

- 공개된 홀짝과 사용 특수카드, 본인 숫자, 승패를 만족하는 상대 숫자 후보
- 위장은 표시 홀짝을 직접 고르므로 해당 라운드의 표시 홀짝은 후보 제한에 사용하지 않음
- 본인이 정찰을 사용했다면 확인한 범위
- 본인의 예측이 성공했다면 예측한 숫자와 실제로 공개된 남은 타일 1장

상대의 숨겨진 현재 선택·정확한 전체 손패·미사용 특수카드는 추가로 전달하지 않습니다. 정보가 충분하지 않으면 숫자 후보를 여러 개 유지합니다. 과거 기록은 경기 종료까지 누적되며, 재경기에서는 새 엔진으로 초기화됩니다.

최대 512개의 사용 숫자 조합을 계산해 모든 기록과 일치하는 사용 내역을 남깁니다. 이미 사용됐음이 확정된 숫자는 제외하고, 불확실한 숫자는 남아 있을 가능성을 나눠 평가합니다. 예측으로 확인한 남은 숫자는 그 정보를 얻은 라운드까지 미사용이었다는 제약이며, 이후에는 상대가 사용할 수 있습니다. 정보가 없거나 기록이 모순되면 1~9 균등 가정으로 돌아갑니다.

이 가중치는 가능한 사용 내역과 남은 숫자를 균등하게 보는 추정값입니다. 상대의 실제 행동 확률을 학습한 모델이 아닙니다.

## 카드 보존과 위험도

각 보유 숫자에 대해 추정 상대 숫자와 비교한 승패 점수를 계산합니다. 기존 AI가 낮은 숫자에 역전을 사용하는 조건도 반영하며, 상대의 아직 공개되지 않은 특수카드는 읽지 않습니다.

- 초반이고 목숨·실탄 상태가 안전하면 높은 숫자를 소모하는 비용을 부여합니다.
- 남은 라운드가 줄면 보존 비용이 감소합니다.
- 목숨이 줄거나 실탄 수가 늘면 패배의 비용을 높이고 보존 비용을 줄입니다.
- 점수가 같으면 무작위로 선택합니다. 항상 현재 손패 안의 숫자를 선택합니다.

현재 계수는 기본 휴리스틱입니다. 승률 향상을 보장하는 최적 전략이나 강화학습이 아니므로 실제 플레이로 밸런스를 조정해야 합니다.

## 베팅·위장·힌트

AI의 베팅은 보유량 안에서 1~3칩 무작위이며 0칩이면 0칩입니다. 전략적 베팅액 최적화는 아직 없습니다. 위장 사용 시 표시할 홀짝을 무작위로 선택합니다. 힌트는 베팅과 같은 30칩 시작 잔액을 쓰며, 라운드당 둘 중 하나만 구매할 수 있습니다.

## 검증

초반·후반·위험 상황의 선택 차이, 사용 확정·불확실 숫자 추정, 예측 정보의 유효 시점, 정찰·예측의 개인 정보 분리, 위장·역전 처리, 스냅샷 변경에 대한 독립성, 라운드가 바뀐 뒤 기록 유지와 기존 전체 테스트를 검사합니다.

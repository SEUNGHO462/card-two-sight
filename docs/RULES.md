# CARD TWO SIGHT 게임 규칙

## 진행 순서

메인 → 캐릭터 선택 → 온라인·연습 모드 선택 → 대기방 → 특수카드 2장 선택 → 베팅 → 숫자 선택 → 특수카드 사용 여부 확정 → 숫자 대결 결과 → 패배 시 실탄 추가 → 탄창 회전 → 탄실 선택·힌트 구매 → 격발 → 룰렛 결과 → 다음 라운드 또는 최종 결과.

다음 라운드는 베팅부터 시작합니다. 연습 모드는 규칙 기반 AI와 진행하며, 온라인 모드는 서버가 선택과 판정·칩 정산을 처리합니다. 캐릭터는 외형만 다르고 능력 차이는 없습니다.

## 숫자 대결

- 각자 숫자 타일 1~9를 한 장씩 가집니다. 사용한 타일은 재사용할 수 없습니다.
- 높은 숫자가 승리하며, 같은 숫자는 무승부입니다. 예외로 1은 9를 이깁니다.
- 양쪽 숫자가 확정되면 특수카드 사용 여부를 선택합니다. 양쪽 모두 확정해야 판정합니다.
- 선택은 확정 전까지 바꿀 수 있고, 확정 후에는 취소할 수 없습니다.
- 상대의 정확한 숫자는 판정 후에도 숨기고 홀짝만 표시합니다. 위장을 사용했다면 표시된 홀짝이 실제와 다를 수 있습니다.
- 경기 기록에는 내 숫자·상대 홀짝·승패·양쪽이 사용한 특수카드를 표시합니다. 베팅 내역은 별도의 칩 계산 내역에서 확인합니다.

## 특수카드

경기 시작 전 4종 중 서로 다른 2장을 직접 선택합니다. 미사용 카드 종류는 상대에게 공개되지 않습니다. 라운드당 최대 1장, 카드마다 경기 중 한 번 사용할 수 있으며 사용하지 않고 넘길 수도 있습니다. 다시 하기에서는 새로 선택합니다.

| 카드 | 효과 |
|---|---|
| 역전 | 해당 라운드는 낮은 숫자가 승리합니다. 양쪽이 사용하면 상쇄되며, 1이 9를 이기는 예외는 항상 유지됩니다. |
| 정찰 | 판정 후 상대 숫자가 1~4 또는 5~9 중 어느 범위인지 본인만 확인합니다. |
| 위장 | 상대에게 보여줄 홀수·짝수를 직접 선택합니다. 실제 홀짝과 같게 표시하거나 반대로 표시할 수 있으며, 실제 숫자와 승패는 바뀌지 않습니다. |
| 예측 | 상대 숫자를 정확히 맞히면, 상대의 남은 타일 중 한 장을 본인만 확인합니다. 남은 타일이 없으면 추가 공개는 없습니다. |

사용한 특수카드 이름은 판정 후 양쪽에 공개합니다. 정찰·예측으로 얻은 정보는 상대에게 공개하지 않습니다. 위장을 쓴 상대의 표시 홀짝만으로 실제 홀짝을 단정할 수 없습니다.

## 보유 칩과 베팅

- 각자 **30칩**으로 경기를 시작합니다. 베팅과 힌트 구매에 같은 잔액을 사용합니다.
- 매 라운드 숫자 선택 전에 각자 **1·2·3칩** 중 하나를 선택해 확정합니다. 보유량보다 많이 걸 수 없습니다.
- 확정 즉시 해당 금액을 보유 칩에서 차감합니다. 취소하거나 다시 베팅할 수 없습니다.
- 양쪽 모두 확정하면 베팅 금액을 공개하고 숫자 선택으로 넘어갑니다.
- 베팅 확정 대기 중 상대 보유 칩은 상대 베팅이 차감되기 전 잔액을 표시하며, 상태는 ‘상대 베팅 확정’으로 표시합니다.
- 두 사람이 건 금액 중 **적은 금액만큼씩** 승부합니다. 초과분은 원래 주인에게 반환합니다.
- **숫자 대결 승자**가 양쪽의 승부 칩을 받습니다. 숫자 대결이 무승부면 각자 건 금액을 전부 돌려받습니다.
- 칩이 0개면 0칩으로 확정하고 경기를 계속합니다. 이때 승부 칩은 0개이므로 상대 베팅도 전부 반환됩니다.
- 다음 라운드에 칩을 추가 지급하지 않습니다. 칩이 많아도 최종 승리 조건은 바뀌지 않습니다.

### 정산 예시

각자 30칩에서 내가 3칩, 상대가 2칩을 걸고 내가 이긴 경우:

| 단계 | 내 칩 | 상대 칩 |
|---|---:|---:|
| 시작 | 30 | 30 |
| 베팅 차감 | 27 | 28 |
| 내 초과분 1칩 반환 | 28 | 28 |
| 승부 칩 4개를 내가 획득 | **32** | **28** |

무승부면 30·30으로 돌아갑니다. 힌트를 구매했다면 그 비용만큼 전체 칩 합계가 줄어듭니다. 칩 계산 내역에는 베팅 차감·초과분 반환·승부 칩 획득·힌트 비용을 잔액과 함께 표시합니다.

베팅 확정 대기 중 연결이 끊기면 맡긴 칩을 반환합니다. 양쪽 베팅 확정 후 숫자 대결 판정 전에 끊기면 초과분을 반환하고 남은 플레이어에게 승부 칩을 지급합니다. 이미 정산한 베팅은 다시 지급하지 않습니다.

## 리볼버와 승리 조건

- 각자 탄실 **9개**, 목숨 **3개**, 초기 실탄 **1발**로 시작합니다.
- 숫자 대결에서 패배하면 원하는 빈 탄실에 실탄 1발을 추가합니다. 승리·무승부면 실탄 수를 유지합니다.
- 기존 실탄이 있는 칸에는 추가 장전할 수 없습니다. 최대 실탄은 9발이며, 격발 후에도 누적 실탄 수는 줄지 않습니다.
- 장전 단계에서 본인 실탄 배치를 확인할 수 있습니다. 회전 후에는 실탄 위치를 숨깁니다.
- 탄실 1~9 중 하나를 선택하고 필요하면 힌트를 구매한 뒤 격발합니다. 양쪽이 확정하면 결과를 확인합니다.
- 실탄에 맞으면 목숨 1개가 줄고, 빈 탄실이면 유지합니다.
- 한쪽 목숨이 0이면 해당 플레이어가 패배합니다. 양쪽 모두 0이면 무승부입니다.
- 둘 다 9라운드까지 생존하면 **숫자 대결 승수**를 비교합니다. 승수가 같으면 무승부입니다.
- 연결 종료·중도 이탈은 이탈자의 패배입니다. 양쪽이 다시 하기를 선택하면 새 경기를 시작합니다.

## 힌트 상점

힌트 비용은 베팅과 같은 보유 칩에서 차감합니다. **매 라운드 두 종류 중 하나만 한 번 구매**할 수 있습니다. 하나를 사면 그 라운드에는 두 구매 버튼이 모두 잠깁니다. 다음 라운드에는 다시 하나를 구매할 수 있습니다.

| 힌트 | 비용 | 효과 |
|---|---:|---|
| 범위 탐색 | 4칩 | 선택한 탄실이 속한 구역 1~3 / 4~6 / 7~9의 실탄 개수를 확인합니다. |
| 탄실 검사 | 8칩 | 선택한 탄실 한 칸이 실탄인지 빈칸인지 정확히 확인합니다. |

- 회전이 끝난 뒤 탄실을 선택해야 구매할 수 있으며, 칩이 부족하면 구매할 수 없습니다.
- 힌트 결과는 구매한 본인에게만 보입니다. 구매 후 탄실 선택은 바꿀 수 있습니다.
- 구매 내역에는 조사한 탄실·구역과 라운드를 표시하며, 경기 종료까지 최신순으로 남깁니다.
- 실탄 위치는 다음 라운드에 다시 회전하므로 이전 라운드의 힌트가 현재 위치를 보장하지 않습니다.

# 게임 규칙 · 구현 기준

## 핵심 흐름

메인 → 캐릭터 선택 → 접속/연습 → 대기방 → 숫자 선택 → 특수카드 선택 → 숫자 대결 결과 → 탄실 선택/힌트 → 격발 확인 → 두 사람 준비 대기 → 룰렛 결과 → 다음 라운드 또는 최종 결과.

- 플레이어마다 숫자 1~9를 한 장씩 가집니다. 한 번 사용한 타일은 재사용할 수 없습니다.
- 높은 숫자가 승리하고 같은 숫자는 무승부입니다. 1 대 9에서는 1이 이깁니다.
- 숫자와 특수카드 선택은 확정 전까지 자유롭게 바꾸고, 확정 이후에는 취소할 수 없습니다.
- 상대 숫자는 판정 후에도 공개하지 않고 홀짝만 보여줍니다. 내 숫자는 내 화면에서 확인합니다.
- 둘 다 결과를 확인해야 다음 단계로 넘어갑니다.

## 특수카드

게임 시작 시 4종 중 중복 없는 2장을 무작위 지급합니다. 라운드당 최대 1장, 카드당 한 번 사용합니다. 특수카드 선택 단계에서 사용하지 않기를 고를 수 있습니다.

| 카드 | 효과 |
|---|---|
| 역전 | 이번 라운드에 낮은 숫자가 승리 |
| 정찰 | 판정 후 상대 숫자가 1~4 / 5~9 중 어느 범위인지 본인만 확인 |
| 위장 | 상대에게 보이는 내 숫자의 홀짝 정보를 반대로 표시 |
| 예측 | 상대의 정확한 숫자를 맞히면 상대의 남은 숫자 한 장을 본인만 확인 |

상대 특수카드 종류와 보상은 전송하지 않습니다. 상대에게는 사용 사실과 남은 장수만 알려줍니다.

## 룰렛 및 종료

- 각자 탄실 9개, 목숨 3개, 초기 실탄 0발입니다.
- 숫자 대결 패배: 내 실탄 +1 / 승리: 내 실탄 -1 / 무승부: 그대로. 범위는 0~9발입니다.
- 매 라운드 실제 실탄 위치는 서버가 무작위 배치합니다.
- 탄실 1~9 중 하나를 고르고, 필요하면 힌트를 산 뒤 탄창 돌리기를 누릅니다.
- 격발 확인 창에서 확정합니다. 양쪽 모두 확정하면 선택한 탄실의 결과를 함께 확인합니다.
- 실탄이면 목숨 -1, 공탄이면 유지합니다. 위험도 k/9는 해당 라운드의 실탄 개수입니다.
- 목숨이 0이면 최종 결과로 이동합니다. 두 사람 모두 0이면 무승부입니다.
- 9라운드를 모두 생존하면 숫자 대결 승리 횟수를 비교합니다. 같으면 무승부입니다.
- 중도 연결 종료는 이탈자의 패배입니다. 양쪽 다시 하기로 새 경기를 시작합니다.

## 힌트 상점

초기 12칩, 힌트마다 2칩, 같은 종류는 라운드당 1회입니다. 결과는 구매한 본인에게만 보입니다.

| 힌트 | 선택 탄실 기준 효과 |
|---|---|
| 범위 탐색 | 선택 탄실이 속한 구역 1~3 / 4~6 / 7~9의 실탄 개수 |
| 구역 비교 | 위 구역과 그다음 구역의 실탄 수를 비교. 7~9 다음은 1~3 |
| 연결 탐색 | 선택 탄실과 바로 다음 탄실, 합계 두 칸의 실탄 개수. 9 다음은 1 |
| 탄실 검사 | 선택 탄실이 실탄인지 공탄인지 정확히 확인 |

힌트 구매 후에도 탄실을 바꿀 수 있습니다. 구매 결과에는 조사한 번호를 표시합니다. 회전 연출은 실탄 위치를 다시 섞지 않습니다. 따라서 구매한 정보는 해당 라운드 동안 유효합니다.

## 이번 구현에서 정한 기본값 — 팀 확인 필요

대화에 여러 후보가 있어 플레이 가능한 버전을 위해 아래를 기본값으로 두었습니다.

1. 목숨은 3개.
2. 역전 두 장은 상쇄. 역전 상황에서도 1이 9를 이기는 예외는 유지.
3. 예측 보상은 특수카드 추가 대신 남은 상대 숫자 한 장 공개. 마지막 라운드는 남은 카드가 없어 추가 공개 없음.
4. 지급 특수카드는 이전 1장 초안 대신 최신 초안의 2장.
5. 힌트 시작 칩 12개, 가격 2개, 라운드별 같은 종류 중복 구매 금지, 칩 추가 지급 없음.
6. 9라운드 생존 시 목숨 수보다 숫자 대결 승수를 기준으로 최종 판정.
7. 6개 캐릭터는 외형만 다르며 능력 차이 없음.

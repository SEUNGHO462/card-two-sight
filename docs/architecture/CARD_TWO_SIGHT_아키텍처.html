동시 처리와 정보 보호

서버 송수신·AI·DB 작업을 스레드/Executor로 분리합니다. synchronized·BlockingQueue·AtomicBoolean을 사용합니다. 화면 반영은 Gdx.app.postRunnable로 전달합니다. 상대의 정확한 현재 숫자·미사용 특수카드·실탄 배치는 공개하지 않습니다.


기록 저장과 확인

온라인은 서버 DB에, AI는 로컬 DB에 FINAL 결과를 저장합니다. 로그인은 없으며 설정·누적 승패 JSON도 유지합니다. DB기록조회.bat 또는 MySQL 터미널로 확인합니다. 게임 화면의 DB 기록 버튼은 제거된 상태입니다.


검증 범위

자동 테스트 49개: 실제 TCP 소켓·MySQL·AI 저장 포함. 두 물리 PC 및 외부망 실제 대전은 별도 확인이 필요합니다. Tailscale·중앙 서버·클라우드 배포를 현재 구현으로 표시하지 않았습니다.

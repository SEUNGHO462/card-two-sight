# AI 연습 대기방과 화면 정리

- 설정·테이블 나가기 창의 제목을 테두리 안으로 옮겨 글자와 선이 겹치지 않게 했습니다.
- 캐릭터 선택의 큰 이름과 작은 이름 버튼을 왼쪽 정렬하고 불필요한 안내 문장을 제거했습니다.
- AI 대기방에서는 방 비밀번호·복사·접속 인원을 숨깁니다. 온라인 대기방에는 유지합니다.
- EASY: 남은 숫자 중 낮은 세 개에서 무작위 선택, 특수카드 사용 안 함.
- NORMAL: 숫자와 특수카드를 무작위 선택합니다.
- HARD: 상대 숫자를 1~9로 가정해 승률을 고려하고 특수카드 및 칩을 사용하는 탄실 검사를 활용합니다. 상대 비공개 카드나 실제 실탄 배치를 직접 읽지 않습니다.
- 연습 상대는 6명 중 선택하며 게임 시작 후에도 선택한 상대가 유지됩니다.
- 대기방에서 설정을 바꾸면 준비 상태가 취소됩니다. 다시 준비한 뒤 시작합니다.
- 난이도와 상대 설정은 현재 실행 중에 유지되며 별도의 저장 파일에는 기록하지 않습니다.

검증: 기존 테스트 및 난이도 전략·탄실 지식 사용·상대 변경과 준비 상태 초기화 테스트 통과. 실제 화면 미리보기에서 설정, 이름 정렬, 난이도 변경, 상대 선택 창, 나가기 창, 선택한 상대와 게임 시작까지 확인했습니다.

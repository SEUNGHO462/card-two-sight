# 연습 모드와 대기방

## 실행과 설정

- 접속 화면에서 연습 모드로 입장합니다. 외부 서버를 켤 필요가 없습니다.
- 대기방에서 난이도와 상대 캐릭터 6명 중 하나를 선택합니다.
- 설정을 바꾸면 준비 상태가 취소되므로 다시 준비한 뒤 시작합니다.
- 선택한 상대는 경기에서도 유지합니다. 난이도·상대 설정은 실행 중에 유지하며 별도 파일에 저장하지 않습니다.
- 온라인·연습 대기방 모두 이전 ‘마지막 테이블 / 방 비밀번호 / 복사’ 패널은 표시하지 않습니다. 온라인 비밀번호는 접속 화면에서 직접 입력합니다.

## AI 행동

| 난이도 | 숫자 선택 | 특수카드·힌트 |
|---|---|---|
| 쉬움 | 남은 숫자 중 낮은 세 장에서 무작위 | 특수카드를 사용하지 않음 |
| 보통 | 남은 숫자 전체에서 무작위 | 남은 카드와 라운드에 따른 무작위 사용 |
| 어려움 | 공개 관찰로 상대의 남은 숫자를 추정하고 목숨·실탄 위험과 높은 숫자 보존을 고려 | 역전·정찰 등을 상황별 사용, 위험 상황에서 잔액이 되면 탄실 검사 |

AI도 30칩으로 시작하고, 매 라운드 보유량 범위에서 1~3칩을 무작위로 베팅합니다. 0칩이면 0칩으로 진행합니다. 위장을 사용할 때는 표시할 홀수·짝수를 무작위로 선택합니다. 힌트 비용은 같은 잔액에서 차감하며 라운드당 하나만 살 수 있습니다.

AI는 상대의 현재 비공개 숫자·손패·실탄 위치를 직접 읽지 않습니다. 위장 라운드의 표시 홀짝은 참·거짓 모두 가능하므로 숫자 후보를 좁히는 근거로 사용하지 않습니다. 머신러닝 모델이 아닌 규칙과 무작위 선택을 결합한 AI입니다. 자세한 내용은 [AI 전략](AI_STRATEGY.md)을 참고하세요.

## 화면

게임 방법은 메인 위의 스크롤 팝업으로 열립니다. 메인에는 누적 승패를 표시하지 않습니다. 누적 승패는 최종 결과에서 확인합니다. 최종 결과에는 진행 라운드 수와 보유 칩 수를 표시하지 않습니다.

## AI 경기 DB 저장

연습 경기를 끝까지 마치면 이 PC의 MySQL에 결과를 저장합니다. `DB기록조회.bat` 또는 MySQL 터미널에서 온라인·AI 구분과 AI 난이도를 확인할 수 있습니다. 기존 누적 기록 JSON도 유지합니다. DB가 없거나 연결이 실패해도 게임은 진행하며 저장 실패를 안내합니다. 자세한 설치·설정은 DATABASE.md를 참고하세요.

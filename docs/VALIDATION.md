## 화면 확인 범위

이전 숨김 libGDX 화면 검증에서는 메인·설정·게임 방법·대기방·카드 선택·베팅·숫자 선택·힌트 구매·격발 결과를 확인했습니다. `.runtime/` 및 `docs/screenshots/`의 이미지는 생성 당시 상태의 참고 자료이며 최신 화면을 자동으로 보증하지 않습니다.

최근 칩 숫자 효과는 0.9초, 금액 표시는 2초 유지 후 0.5초 페이드입니다. 실제 기기에서 읽기 편한지 확인해야 합니다. 자동 화면 검증은 무음이며 스피커 출력은 별도 확인 대상입니다.

## 재검증 명령

```powershell
.\gradlew.bat test :lwjgl3:installDist :server:installDist
.\검증실행.bat
```

두 번째 명령은 테스트·빌드도 함께 수행합니다. 한 번에 전체 확인할 때 사용하며 두 명령을 매번 연속 실행할 필요는 없습니다.

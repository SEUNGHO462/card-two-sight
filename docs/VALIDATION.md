# 검증 결과 · 2026-10-26

## 빌드 및 자동 테스트

Windows x64 / JDK 21.0.12 / Gradle 8.14.3에서 Java 17 대상 코드로 빌드했습니다.

`gradlew.bat test :lwjgl3:installDist :server:installDist` 성공. Gradle Wrapper의 새 다운로드 및 실행도 확인했습니다.

최종 배포 폴더의 게임실행.bat으로도 실행해 9라운드와 최종 결과까지 확인했습니다. Windows의 긴 경로에서 명령 길이 제한이 발생하지 않도록 배포 스크립트의 클래스 경로는 디렉터리 와일드카드 방식으로 수정했습니다.

| 영역 | 테스트 수 | 확인 내용 |
|---|---:|---|
| 공통 규칙 | 9 | 숫자·역전·1 대 9, 9라운드 완주, 타일 중복 방지, 비공개 정보, 힌트 비용, 위장·정찰·예측, 목숨 소진 |
| 기록 저장 | 1 | 한글 키 JSON 저장·재로드, 같은 경기 중복 집계 방지 |
| 실제 소켓 서버 | 2 | 두 TCP 클라이언트 접속, 9라운드, 다시 하기, 이탈 패배, 세 번째 인원·없는 방 거절 |
| 합계 | 12 | 실패 0 / 오류 0 |

서버 테스트는 모의 함수 호출만 사용하는 검증이 아니라 실제 서버 소켓과 별도 클라이언트 소켓을 생성합니다. 두 대의 물리 PC 사이에서의 통신이나 외부 인터넷 서버 배포를 검증한 것은 아닙니다.

## 실제 화면 실행

데스크톱 libGDX 실행본에서 자동 입력으로 연습 게임을 최종 결과까지 진행했습니다. 이전 확인에서는 7라운드 생명 소진, 다른 확인에서는 9라운드 종료에 도달했습니다. 게임 규칙 테스트에서도 두 종료 방식을 별도로 확인했습니다.

`docs/screenshots`의 PNG는 실행한 게임 화면을 저장한 결과입니다. 이미지 생성 도구가 만든 전체 화면 시안과 구분됩니다. 메인·캐릭터·접속·대기방·숫자 선택·특수카드 선택·숫자 결과·탄실·격발 확인·룰렛 결과·최종 결과를 확인했습니다.

화면 검증은 숨김 OpenGL 창과 효과음 비활성 설정으로 수행합니다. 효과음 파일은 배포에 포함되어 있지만 실제 스피커 출력은 이 자동 검증 범위에 포함하지 않았습니다.

## 팀에서 이어서 확인할 부분

- 각자 PC에서 방장/참가자로 접속하고 학교 네트워크의 접속 허용 상태 확인
- 숫자·특수카드·힌트 가격과 목숨 수 밸런스 확정
- 장시간 플레이, 서로 다른 화면 배율, 다중 모니터·음향 장치 확인
- 긴 총격·탄 장전 애니메이션과 맞춤형 자세별 캐릭터 그림 추가

현재 자산은 정지 그림 중심입니다. 타일 클릭·숫자 표시·화면 전환·회전·짧은 반동과 피격 기울임은 코드로 동작합니다. 아직 없는 연출을 완료 기능으로 표시하지 않았습니다.

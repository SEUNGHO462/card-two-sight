# 9칸 리볼버 직접 장전과 최종 결과 표시

- 원래 assets/revolver/wheel.png의 금속 질감과 9칸 디자인을 사용합니다. 기본 실탄 1발, 패배할 때만 1발 추가, 최대 9발 누적입니다.
- 패배 후에는 AMMO_LOAD 단계에서 본인의 기존 실탄 위치를 확인하고 빈칸을 직접 선택합니다. 선택 버튼으로 장전을 확정하면 그 위치로 삽입하는 장면이 나옵니다. 다음 번호에 자동으로 넣지 않습니다.
- 서버는 범위 밖 번호, 이미 장전된 칸, 추가 실탄이 없는 사용자의 명령, 중복 장전을 거부합니다. 두 사람 모두 필요한 장전을 끝내야 격발 선택 단계로 갑니다.
- 기존 배치에 선택한 탄을 실제로 추가한 뒤, 서버가 비공개 회전 오프셋을 적용합니다. 단순 개수용 가짜 위치가 아닙니다. 회전 후 위치는 숨기며 힌트로 조사할 수 있습니다.
- 승리·무승부에는 추가 실탄을 넣지 않습니다. 회전 후 필요한 힌트를 확인하거나 바로 격발합니다.
- 상대에게 본인의 기존 실탄 배치나 장전 위치를 보내지 않습니다. Snapshot.loadedChambers는 AMMO_LOAD에서 본인 배치만 담으며, 회전이 끝난 실제 배치는 전송하지 않습니다.
- 칩 부족 안내와 라운드별 힌트 구매 내역 보존은 유지합니다.

최종 결과는 서버의 winner를 기준으로 표시합니다. 숫자 대결 승수가 높더라도 목숨이 먼저 0이 되면 최종 패배입니다. 최종 승자·숫자 대결 승수·남은 목숨·종료 사유를 구분해 표시하고, 제목과 부제는 같은 중심선에 맞췄습니다. 다시 하기와 메인으로 버튼은 각각 400×68로 같습니다.
